# Ali Zabetpour — Portfolio

Personal portfolio for Ali Zabetpour, Front-end Developer & Software Engineer. The site uses the Next.js App Router and is deployed as a standalone Node.js server.

## Requirements

- Node.js 20.9 or newer
- npm

## Development

```bash
npm ci
npm run dev
```

## Checks and production

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

The site is statically rendered. `npm start` serves the standalone output created by `npm run build`.

## Project structure

- `src/app`: root layout, homepage, metadata, sitemap, and robots routes.
- `src/components` and `src/core`: page sections and shared UI components.
- `src/static/components`: personal content and experience data.
- `src/styles`: shared Sass variables and global styles.
- `public`: profile image, fonts, and favicon.

Update personal content in `src/static/components`. Keep employment start dates blank when they are unknown. The CSGO BAZAR website link is intentionally omitted until its production domain can be verified.

## Search visibility

The site uses `https://alizabetpour.ir` as its canonical host. Metadata, Person/ProfilePage JSON-LD, `robots.txt`, and `sitemap.xml` are generated by the App Router. Domain ownership verification and sitemap submission should be completed in Google Search Console and Bing Webmaster Tools after deployment.
